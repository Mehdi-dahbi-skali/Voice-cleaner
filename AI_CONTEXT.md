# 🤖 Voice Cleaner - AI Context & Integration Manifesto

This file provides a compressed technical context for AI Agents and Developers to understand the project structure and facilitate the connection between the Flutter Frontend and Spring Boot Backend.

## 1. Project Overview
- **Name**: Voice Cleaner
- **Goal**: Professional voice recording and AI-driven background noise removal.
- **Frontend**: Flutter (Material 3).
- **Backend Architecture**: Spring Boot Microservices (Cloud Native).
    - **Discovery**: Netflix Eureka.
    - **Gateway**: Spring Cloud Gateway (Port 8080).
    - **Communication**: OpenFeign (Inter-service).
- **AI Model**: RNNoise (RNN + GRU) for spectral gain estimation.

## 2. Global Architecture (The "Golden Record")
All frontend requests **MUST** go through the Gateway:
- **Gateway URL**: `http://localhost:8080` (Configurable in `AppConfig`).
- **User Service Route**: `/userservice/**` (Auth, Login, Signup).
- **Audio Service Route**: `/audioservice/**` (FileUpload, List, Delete).

## 3. Key Integration Files
- `lib/config/app_config.dart`: **Central Source of Truth.** Contains the Gateway URL and microservice prefixes. Switch `useMockData` to `true` for UI-only testing.
- `lib/services/api_service.dart`: **Central Network Client.** Use `fetchAudios()` and `uploadAudio()` helpers. It handles Multipart and JSON automatically.
- `lib/models/audio_item.dart`: **Data Model.** Implements `fromJson()` and `toJson()`. Fields MUST match backend JSON keys (`id`, `title`, `duration` in secs, `type`, `date`).

## 4. How to Connect a New Feature (Developer/AI Guide)
1. **Define Endpoint**: Add the route in `AppConfig` if not present.
2. **Update Helper**: Add a specific method in `ApiService` (e.g., `fetchUserProfile()`).
3. **Map Model**: Ensure the model handles the JSON structure returned by the Spring service.
4. **Call Service**: Use `final ApiService _apiService = ApiService();` in your Flutter state and call the helper in `initState()` or on button press.
